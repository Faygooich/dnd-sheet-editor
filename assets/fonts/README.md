# Шрифты

Здесь должны лежать два файла шрифта Segoe Script:

- `segoesc.ttf` (обычный)
- `segoescb.ttf` (жирный)

Они принадлежат Microsoft и в этот репозиторий не включены: лицензия не разрешает их распространять.
На Windows они уже есть в `C:\Windows\Fonts`: скопируйте оба файла в эту папку, и редактор заработает полностью (отображение и экспорт в PDF).

Fonts: the two Segoe Script files are Microsoft property and are not included. On Windows copy
`segoesc.ttf` and `segoescb.ttf` from `C:\Windows\Fonts` into this folder.
